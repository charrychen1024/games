操作说明 / 玩法（点击折叠）

玩家 1

  • W A S D 移动
  • J 或 空格 开炮

玩家 2（双人同屏）

  • ↑ ← ↓ → 移动
  • 小键盘 0 / 右 Shift / / 开炮

通用

  • Enter / 空格 / 鼠标左键 确认
  • Esc 返回上一层，P / Esc 游戏中暂停
  • 鼠标 可直接点菜单项

关卡编辑器（CONSTRUCTION）

  • 鼠标左键 涂地形，右键 擦除
  • 方向键 移动光标，空格 放置，Tab 切换地形
  • B 笔刷 8px / 16px，F 填充整屏
  • S 保存到槽位，L 读取，N 新建，C 清空
  • T 立即试玩，Esc 退出

道具

  • ★ 星：火力升级（4 级）
  • ⛑ 头盔：10 秒无敌护盾
  • ⏱ 时钟：冻结所有敌人
  • ⛏ 铁锹：老巢变钢墙
  • 💣 手雷：全歼场上敌人
  • 🚙 坦克：加一条命
