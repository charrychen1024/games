## 二、按我的判断定下的事项

制作要求没有规定、需要实现时决定的地方如下，均可调整。

1. **数值尺度**：
   - 每兵每月口粮 0.25 石，驻军月饷 0.6 两，出征 0.9 两，募兵每人 3 两。
   - 直辖城把赋税的三成起运都城，各省明官府解饷 8%。
   - 有余银的城会自动按每石 1.2 两买粮（市籴）。
2. **闰月表**：只有 1645 年闰六月可以确证，其余按历表推算，已在 `calendar.ts` 注明待考。
3. **开局归属**：济南、大名、归德、睢州、开封、南阳标为“地方豪强”（归属待考），城池卡显示考据说明。
4. **电脑倾向**：
   - 清：先追击大顺、接收北方，“清廷决意南下”之后才转向江淮。
   - 大顺：新败之余，部众逐月离散，用兵只在关中、山西、豫西。
   - 张献忠部：只在四川、湖广西部。
   - 郑氏：守福建。
   - 降意高的下属军镇在清军压境时可能整体归附。
5. **左良玉**：“清君侧”是否发生，取决于乙酉三月时的服从度。玩家可以提前犒赏来避免。
6. **玩家参与的战斗才进入战斗画面**，电脑之间的战斗直接结算。顶栏可切换“部将自动”。
7. **远方战事**：电脑之间的战斗不进入玩家军情，只报易主。
8. **屠城等事件**：用克制的文字直述，不做血腥画面（“扬州之战”史事）。
9. **试玩之后可以继续推进**，规则照常运行，但史事只编到乙酉四月。
10. **地图地形用真实高程**：取 AWS Terrain Tiles 公开高程，重采样成每度 32 格的高程图（约 700KB）。浏览器读入后用代码完成以下几项：
    - 晕渲：西北光源。
    - 分层设色：按海拔和干湿，秦岭淮河以北渐黄，西北高原偏褐，雪线以上积雪。
    - 海深：由浅青到深蓝。
    - 河道入谷：河线沿真实河谷微调。
    - 陆地按 Natural Earth 海岸线裁切。
    - 驿路画成土路，海路画成航道虚线。

    高程图加载前先显示纯色底图。黄河按 1644 年的夺淮入海故道画，不用今天的河道。

| 策略 | 守住扬州 | 守住南京 | 扬州守军（均） | 江北服从（均） | 南京存银（均） | 己方参战（均） |
|---|---|---|---|---|---|---|
| 放任 | 11/30 | 30/30 | 3,016 | 69.3 | 388,719 | 11.8 |

几点解读：
- 增援和交涉都明显改变扬州结局，说明玩家决策确实起作用。
- 补给救不了扬州，因为清军围城后粮送不进去。
- 补给局南京存银反而更多。原因是扬州有粮时，高杰部留在扬州就食；放任局里电脑把高杰部的粮台改到南京，南京要多付约 18 万两关饷。这是规则的连带后果，不是错误。
- 策略都是固定规则，只作基线对照，不代表最优打法。

- **全国地图**：一百五十处城池、关隘、港口，覆盖十四个计入统一的地区（每区至少四处），另有台湾大员（荷兰东印度公司）。旧的“粗粒度大区”全部换成府城，路线按驿路、长江、运河、海路重排。寻路结果缓存，一个月结算约六十毫秒。

- **继统**：明室正统所在的朝廷，君主被俘或身故时，月末由玩家议定继统：拥立宗室即位并改元、请宗室监国待迎旧君、出银十五万两议赎、或由权臣主事。各方案写明支持者与代价。电脑一方自动拥立。朝廷覆亡后，奉明而城最多的势力继承正统，就近迎立宗室，年号随之更替。宗室有潞王、唐王（隆武）、鲁王、桂王（永历）。
- **分裂**：郑芝龙降清时，郑氏玩家选择随郑成功起兵（改领郑成功部，据中左所）、随郑芝龙归清，或父子同心拒降；孙可望降清时，大西玩家选择由李定国统领余部，或孙、李和解。鲁王监国从朝廷分出浙东一支。
- **教育与人才**：顾炎武、黄宗羲、王夫之、方以智、宋应星、傅山等十六人按时出仕。乡里文教低于 40 则推迟；志在抗清者不仕清，改投就近的奉明势力，无处可投则隐居。文教高的城池每年给主官增一点政务。

| 某路之敌已空，兵力闲置 | 当面无敌的一路可“包抄”邻路之敌侧背（杀伤加重、敌军心动摇）；任一路可于回合开始调一半兵马往别路；预备队可在任一合投入任一路；各路皆溃而预备尚在，预备自动顶上中路 |
| 回合数定死 | 不再定死：一方全线溃散、军心崩溃（全军加权士气过低）、鸣金收兵即止；第四合起久战疲惫、士气逐合下降；打到日暮（野战八合、攻城六合）两军各自收兵。界面不再预告共几合，只报第几合与晨午暮 |
| 打法 | 新增“鸣金收兵”：撤出战场、敌军追击（骑兵多则损失大）；电脑在大势已去时也会收兵。攻城节奏重调：守军据墙不计疲惫、单合炮击放缓，坚城仍须数月 |
| 城墙简陋 | 重画：墙体收分、青砖逐块深浅、三层条石基座、马面墩台（正面、侧面、顶面与垛口）、有厚度的垛口与射孔、内侧女墙与马道、墙根阴影、护城河在墙外、砖券门洞与包铁钉门 |

## 九之三、玩法审查的非战斗条目（2026-11-25）

据《玩法独立审查-2026-11-25》第五节，逐条按“同一局面只改一个选择”写了回归测试（`tests/review3.test.ts`）。

| 审查条目 | 处理 |
|---|---|
| 谁完成统一 | 满图且无独立对手时，再看玩家在本阵营里的身份：本方即天下之主为“天下一统”；奉他人号令而直辖计胜之地多于阵营中任何一家，为“扶明定鼎”（扶立之功，算玩家的胜利，不必自立）；否则为“随主一统”，结局写明主导者是谁。三种局面各有测试（`src/core/turn.ts` 的 `unifierRole`） |
| 有城有兵而无人继任 | 主事人被俘或身故而本部无人时，只要还有城或军队就不退场，月末议定：请上级委派一员主事、征辟本地尚未出仕之士、议赎旧主（被俘时），或部众投靠上级或盟友。玩家选投靠则以“部众投靠”收场，结局写明缘由；电脑一方按委派、征辟、投靠的次序自行决断；无城无军仍直接退场。非明廷势力失去主事人，玩家也可在本部诸将中择人主事，不再自动换人（`src/core/military.ts` 的 `succession`、`src/core/regime.ts`） |
| 玩家改换粮台 | 新军令“粮台”（不占政令）：点己方军队的“粮台”，再点要支粮的城。条件与电脑相同：己方或同阵营之城、未被敌围、粮道可通（`supplyChoiceError`）。电脑换台改用同一检查，久欠饷时先找有银之城 |
| 整镇改奉的条件与使程 | 使者路程按驿路远近计（军行日程的六成，每三十日一月，至少一月）：北京到安平两个月，邻城一个月，界面写明“约几个月后可有回音”。一镇之主献城时，全镇随否看诸将：忠于本镇而无降意者、志在抗清者不从，按统军、领兵、守城加权得出随从比例；不从则镇主只以本城与亲兵改投，本镇另推主事、仍奉旧主（`followOdds`）。黄得功部诸将降意高，仍携全镇归附 |
| 海陆通行 | 船队算路时陆路计两倍半，有水路就不无谓舍舟；舍舟登岸后余程立刻按步卒重算；已无船的军队遇到旧计划里的海路，就地改走陆路。一次下令与分段下令走同一条路 |
| 兴学的回报 | 乡里文教高于 50，每高三点，日后成名之士提早一月出仕（至多一年）；每高十点，出仕时政务 +1（至多 +3）。出仕军报写明“较常例早几月”“乡学有成” |
| 欠饷的长期后果 | 军队记下积欠饷银与连续欠饷月数。欠一两月只压低士气上限（每月 −3，至多 −24，士气随之回落）；连欠满四月，就所驻本方城池索饷（民心 −3、吏治 −1）；索不到而本方府库其实有银（挪饷不发），每月逃散 1%—4%。粮台有余银即补发旧欠，补清时士气回升并有军报。军队面板显示欠饷月数、积欠与士气上限。电脑一方也会从有余银的城调银补饷。举镇皆穷者不另逃散，只压士气、扰地方——这样不改动电脑各镇的整体兵力（十二局六年平均野战兵力与改动前相差在随机起伏之内） |

## 九之五、每月钱粮预估与募兵（2026-11-25）

## 九之六、经济数值审计（2026-11-25）

审计工具：`npx tsx tools/econ-audit.ts [月数] [种子]`（五家开局分季收支表与空过走势）。另以“只跑月结、不打仗”的纯经济模拟和多种子整局空过对照，每项改动单独量过。

**诊断**

| 项 | 实测 | 判断 |
|---|---|---|
| 收入结构 | 每万口每月赋税约 128 两、田粮约 127 石，粮价 0.9—1.6 两，粮银收入约各半 | 合理 |
| 支出结构 | 兵一人每月粮 0.25 石（约 0.22 两）+ 银 0.6 两（出征 0.9），支出七成是银 | 与收入比例不称，是“粮多银少”的根源 |
| 粮无去处 | 弘光两年存粮 177 万→488 万石；赈济一次耗粮超过大城一月田粮，回本要五年以上 | 粮食没有出路 |
| 小城空库 | 弘光 31 城两年里 191 个“城·月”府库见底（起运三成上缴，小城驻军饷不够） | 起运集中钱粮是设计，但小城看着总缺钱 |
| 清、大顺、大西 | 清 8 城月入银 2.3 万、兵费 9.8 万，存银约撑半年 | 以掠代养、必须扩张的设计，不改；记在此处 |
| 劝农、通商 | 6—11 个月回本 | 合理 |
| 加派、劝饷 | 加派 12—21 个月后得不偿失；劝饷一次约 1—1.7 个月赋税 | 合理 |
| 募兵银 | 3 两一人，约当 3.7 个月兵费 | 合理 |

**试过而放弃的**：把兵费改成多粮少银（0.4 石 + 0.45 两）。弘光、郑氏银两宽裕了，但清、大顺、大西缺粮挨饿——断粮逃散每月 5%，远重于欠饷，空过两年清的兵力从 21 万掉到 10 万。起运“先留本城兵饷”也试过：小城不再空库，但钱留在了用不上的地方（驻军欠饷几乎无后果），治所供养的出征军反而欠饷逃散。两项都撤回。

**采用的改动**

| 改动 | 内容 |
|---|---|
| 玩家城池自动粜余粮 | 原先只有电脑会自动卖粮。玩家的城田粮常年自给有余、银不够两月兵饷时，自动卖出超过六个月口粮的余粮；缺粮之城不卖。电脑一方与玩家下属沿旧例 |
| 赈济减半 | 每万口每月放粮 150 石 → 100 石（大城约当一月田粮的六七成），民心仍 +3 |
| 陈粮霉变 | 超出本城六个月用度（另留每万口 300 石）的存粮每月耗百分之一，逐项预估里列出 |
| 欠饷逃散只罚“本可发而不发” | 原按全势力存银判断；改为只算可设为此军粮台（未被围、粮道通）的城的存银。粮台被围、别城的银运不进来，不再算挪饷 |

**效果**（弘光，纯经济两年）：存银 266.7 万→280.6 万，存粮 487.6 万→373.2 万，府库见底的城·月 191→93。各家整局空过两年的兵力与改动前相当（电脑大西 103k 对 104k；玩家清、大西相当）。玩家大顺空过时兵力略低（约 129k 对 142k）：御营粮台太原早失，玩家不改粮台、西安却有卖粮得来的银，按规矩算挪饷——这是玩家不作为的后果，月报每月都有“粮台已失”与欠饷急报。

## 九之八、议和与交涉（2026-11-25）

原先的外交只有玩家遣使（下月得知成败）与电脑宣战；电脑从不主动议和、结盟、招抚，各家之间也没有外交往来。新增 `src/core/diplomacy.ts`：

| 内容 | 规则 |
|---|---|
| 来使求和 | 与你交战、兵力不及你七成、主将不甚好战的一家遣使求和，附犒银。可准和受银（停战一年）、索要一城或加倍犒银（成算看对方虚实与主将脾性，不成则对方更恨）、拒绝 |
| 强敌招抚 | 兵力两倍于你、据五城以上的敌家遣使招抚。可斩使明志、虚与委蛇（约五成换四个月停战）、受抚归附（改奉其号令）；明室朝廷不能受抚 |
| 强邻索饷 | 不交兵而兵力远胜、主将好战的邻家索要犒军银。给银求安（停战一年）、讨价还价给一半（成算看主将）、拒绝（约六成起兵来攻） |
| 通好互市 | 相安而兵力相当的邻家来约：两年互不相犯，两家各得互市之利 |
| 议盟 | 与你同受天下最强一方之逼的邻家来议结盟；清志在一统，不与人结盟，只招抚 |
| 讨价还价 | 你遣使议和、停战、结盟，差一点议成时对方开条件要一笔银子，由你定夺；交战中谈崩，使者约三成会被扣 |
| 外交动向 | 电脑各家之间战事不利者求和、同受强敌者议盟，成败写进月报（“【动向】”）；停战期满复为交战也有报 |
| 史事 | 海澄议和（1653—1654）：清许郑成功海澄公与四府、要其剃发。郑氏玩家可借和议休兵筹饷（史实）、受封归顺、严拒；电脑郑氏按史借和议筹饷 |

条件：来使须与你接壤或相去两站之内；有宗主的下属不自行议和；同一家八个月内不再来，任何来使之间至少隔两个月。实测四十八个月里玩家收到三到七次来使（视所在地势而定），另有二到五条外交动向；电脑各家两年后的兵力与改动前一致。

## 九之十二、人物与人才（2026-11-26）

- 起因：开局约 125 位史实人物，弘光 31 城有 25 城无主官，各家相仿；电脑从不派主官；被俘者押着无人处置；主官只影响赋税田粮。
- **特长**（`src/core/people.ts`）：名臣据史而定，其余按能力推出。主政之城：理财赋税 +12%、屯田田粮 +12%、贪墨赋税 −10%；清廉、严苛、贪墨改变吏治趋向，抚民、严苛改变民心趋向；善守每月修城、守城士气 +8；练兵募兵上限 +30%。出使劝降：辩才 +8%。作战：骁勇统军 +6，水战（水师过半）+8，智谋多一道计策。
- **主官治城**：有主官之城，吏治每月向 25+政务×0.55（加特长）靠拢一点，民心向 25+威望×0.45+政务×0.1 靠拢；统军 60 以上者每月修城一点。无主官之城不升不降，赋税田粮按政务 40 计。
- **招贤**：城池政令台“招贤”，花 3000 两延请一位本地人物（举人、生员、乡绅、营将、千总等），能力多在四五十，文教越高越多能吏，约 6%＋（文教−50）/400 的机会出众（66–82）并带特长；本城无主官则暂署；同城六个月一次。
- **俘虏**：被俘者记下为谁所执。人物面板“俘虏”页可劝降（看降意、忠诚、志节；同朝易劝，异朝主战者难，忠诚 95 以上至多 5%）、释放（各城民心 +1）、处斩（其旧主上下主战 +5）。电脑每半年劝降一次，押满两年遣归。
- **电脑**：每月把闲人派往空缺之城（大城先、政务高者先），仍有空缺且府库宽裕时每月招贤一至两城。四年模拟（`npx tsx tools/char-audit.ts`）：清的空缺从 23 降到 2–6，大顺、大西降一半以上；各家强弱走势与之前相近。
- **画像**：袍色按品级（绯、青、绿），补子禽鸟分品；年纪据生年（55 岁以上须发皆白、46 岁以上斑白、28 岁以下无须）；文臣乌纱展角长短不一、年高望重者戴忠静冠，手执笏、书卷，理财者持算盘、屯田者持稻穗；士人持扇或书卷；武将按特长持枪、弓、剑或羽扇，甲分鳞甲、札甲、泡钉甲，高阶有护心镜，偏裨戴笠盔；背景调入本人色调（主战偏赭红、主和偏青墨），纹样有窗棂、书架、梅枝、月影、竹影、旌旗、海浪、烽烟；身形微侧各不相同。女子不披甲者画高髻簪钗。
